Setup sequence

What happens in order

sequenceDiagram
  participant iOS as iPhone
  participant SB as Supabase
  participant Device as AIOS Box
  participant Cloud as aios cloud
  participant CF as Cloudflare

  note over iOS,SB: 1 Sign in
  iOS->>SB: Authenticate user
  SB-->>iOS: Session JWT

  note over iOS,Device: 2 Put the box on WiFi over Bluetooth
  Device-->>iOS: Advertise BLE and WiFi list
  iOS->>Device: Encrypted SSID and password
  Device->>Device: Join WiFi
  Device-->>iOS: LAN IP and provisioning key

  note over iOS,Cloud: 3 Bind the box to the account
  iOS->>Cloud: Request pairing code with JWT
  Cloud-->>iOS: pairing_code
  iOS->>Device: Send pairing code on LAN
  Device->>Cloud: Redeem code
  Cloud-->>Device: device token and tunnel token
  Device->>CF: Start public tunnel
  Device-->>iOS: local_token

  note over iOS,CF: 4 Use the box
  iOS->>Device: On same WiFi with local_token
  iOS->>CF: From anywhere with local_token
  CF->>Device: Forward to box
  Device->>Cloud: Relay heartbeat and remote commands

Bluetooth only carries Wi‑Fi credentials. Account bind currently needs the phone on the same LAN as the box. After that, Cloudflare Tunnel covers off-network use.
