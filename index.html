How pairing works

Phone puts the box on Wi‑Fi over Bluetooth, then binds it to the user through aios-cloud. 

sequenceDiagram
  actor Phone as Phone
  participant Box as AIOS Box
  participant Cloud as aios-cloud

  rect rgb(230, 242, 239)
    Note over Phone,Box: 1. Get the box online over Bluetooth
    Box-->>Phone: Advertise BLE and WiFi list
    Phone->>Box: Encrypted SSID and password
    Box->>Box: Join WiFi
    Box-->>Phone: LAN IP and provisioning key
  end

  rect rgb(247, 246, 243)
    Note over Phone,Cloud: 2. Bind the box to the user account
    Phone->>Cloud: Sign in and request pairing code
    Cloud-->>Phone: pairing_code
    Phone->>Box: Send pairing code to box
    Box->>Cloud: Redeem code
    Cloud-->>Box: device token and tunnel
    Box-->>Phone: local_token
  end

  rect rgb(240, 238, 232)
    Note over Phone,Cloud: 3. Everyday use
    Phone->>Box: API calls with local_token
    Box->>Cloud: Relay and public tunnel
  end

Bluetooth never carries account tokens — only Wi‑Fi credentials. Later, if the box moves networks, the phone reuses the stored provisioning key (no fresh ECDH). Unpair drops the account link; factory-reset also wipes that key.
